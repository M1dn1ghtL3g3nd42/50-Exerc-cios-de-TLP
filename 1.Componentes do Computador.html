Componentes do Computador

O que é a CPU?
R: A CPU é a unidade Central de Processamento responsável por executar as instruções e processar dados no computador.
O que é a Memória RAM?
R: A memória Ram é a memória de acesso aleatório de curto prazo utilizada para armazenar dados temporários dos programas em execução.
Disco Rígido (HD/SSD)
R: O HD é o dispositivo de armazenamento não volátil responsável por guardar dados permanentemente no sistema.
