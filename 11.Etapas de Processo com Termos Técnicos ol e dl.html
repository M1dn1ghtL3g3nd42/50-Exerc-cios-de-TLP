11: Etapas de Processo com Termos Técnicos

  1. Fase de Requisição
    Handshake TCP
    Processo de conexão de três vias efetuado entre o cliente e o servidor antes do envio de dados.
  2. Fase de Resposta
    Status Code 200 OK
    Código de resposta HTTP que indica que a requisição foi efetuada com sucesso.
