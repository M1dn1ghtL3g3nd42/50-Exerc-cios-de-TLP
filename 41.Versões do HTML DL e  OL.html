Versões do HTML

HTML4.01
Lançado em 1999, padronizou o uso da linguagem para a Web moderna inicial.
  1. Uso massivo de tabelas para layout.
  2. Separação estrita recomendada do estilo com introdução do suporte a CSS.
HTML5
Lançado oficial em 2014, trouxe recursos avançados para aplicações web modernas.
  1. Novas tags semânticas (<header>, <article>, <footer>).
  2. Suporte nativo a multimédia com as tags <video> e <audio>.
  3. Integração de APIs avançadas (Canvas, Geolocalização, Armazenamento Local).
