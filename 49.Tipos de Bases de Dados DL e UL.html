Tipos de Bases de Dados

Bases de Dados Relacionais (SQL)
Organizam dados em tabelas estruturadas com relacionamentos bem definidos.
  • PostgreSQL
  • MySQL
  • Oracle DB
Bases de Dados Não Relacionais (NoSQL)
Armazenam dados não estruturados ou semi-estruturados em documentos, chave-valor ou grafos.
  • MongoDB (Documentos)
  • Redis (Chave-Valor)
  • Neo4j (Grafos)
