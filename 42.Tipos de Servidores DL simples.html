Tipos de Servidores

Servidor Web
Armazena e disponibiliza páginas web via protocolo HTTP/HTTPS para os clientes navegadores.
Servidor de E-mail
Gere a receção, armazenamento e encaminhamento de mensagens de correio eletrónico.
Servidor DNS
Converte nomes de domínio (ex: www.site.com) em endereços IP numéricos compreensíveis por máquinas.
Servidor FTP
Facilita o envio e descarregamento seguro de ficheiros grandes entre computadores.
