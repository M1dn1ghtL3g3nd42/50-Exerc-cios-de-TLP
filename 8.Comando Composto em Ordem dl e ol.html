Comando de Redirecionamento e Filtragem
Execução sequencial para filtrar e guardar dados de processos.
  1. Executar ps aux para listar todos os processos.
  2. Utilizar o operador pipe | para direcionar a saída.
  3. Filtrar com grep "python".
  4. Redirecionar o resultado com > para um ficheiro de texto.
